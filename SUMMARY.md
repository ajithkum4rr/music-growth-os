# Music Growth OS Summary

## Purpose

This repository is a complete Music Growth Operating System for `ajkay`.
It is designed to guide an independent artist through release planning, promotion, analytics, optimization, automation, and AI-assisted support.

## What is included

- 26 phase-based docs under `docs/`
- SOPs in `sops/`
- templates in `templates/`
- checklists in `checklists/`
- agent definitions in `agents/`
- analytics, campaign, experiment, research, and RAG starter docs
- a live campaign tracker in `CURRENT-RELEASE.md`
- a usage guide in `USAGE-GUIDE.md`

## Key entry points

- `README.md` — project overview
- `USAGE-GUIDE.md` — how to use this repo manually, with agents, and with automation
- `PROJECT-STARTER.md` — first execution tasks
- `CURRENT-RELEASE.md` — active campaign tracker
- `MASTER-PLAN.md` — system architecture and phase dependencies
- `ROADMAP.md` — short-term rollout plan

## Core structure

### Main folders

- `docs/` — phase-level manuals and execution guides
- `agents/` — agent roles, scopes, and guidance
- `templates/` — templates for campaigns, emails, pitches, and reporting
- `checklists/` — checklist templates and execution lists
- `sops/` — standard operating procedures
- `analytics/` — analytics tracking starter docs
- `campaigns/` — current campaign planning
- `experiments/` — optimization and A/B test logging
- `rag/` — AI retrieval-augmented generation notes
- `research/` — research planning and notes
- `scripts/` — repository scripts

## Quick start

1. Open `README.md` for a high-level overview.
2. Read `USAGE-GUIDE.md` for a full workflow with manual, agent, and automation guidance.
3. Open `PROJECT-STARTER.md` and complete the first execution tasks.
4. Fill `CURRENT-RELEASE.md` with your active campaign details.
5. Start with `docs/00-foundation/README.md` and move through the phase docs in order.
6. Use `templates/` and `checklists/` to execute work and capture outputs.
7. Use `agents/README.md` only after you understand the manual workflow.

## Recommended start path

1. Read `USAGE-GUIDE.md`.
2. Open `PROJECT-STARTER.md` and execute the first tasks.
3. Fill `CURRENT-RELEASE.md` with your current campaign details.
4. Start with `docs/00-foundation/README.md` and proceed through the phases.
5. Use `templates/` and `checklists/` to capture and execute tasks.
6. Use `agents/README.md` for AI-assisted support once the manual process is understood.

## Agent support

Agents are documented assistants for research, planning, and decision support.
Use them only after you understand the manual process and have clear prompts based on your current phase.

## Automation guidance

Automation should come after you prove the manual workflow.
Start with low-risk tasks such as reporting exports, reminders, and status tracking.

## Notes

- The system is designed for a solo artist or small team.
- Human judgment comes first; agents and automation are support tools.
- This repo is ready to use and is already structured with all required phase docs and supporting files.
