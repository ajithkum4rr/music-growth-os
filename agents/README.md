# Agents

This folder contains AI agent definitions and role design for the Music Growth OS.

## Purpose

Agents should be documented support systems, not autonomous decision-makers.

Read `../USAGE-GUIDE.md` for the full repo workflow and for guidance on when to use agents versus manual execution.

## Agent principles

- Agents should recommend and summarize, not execute changes without explicit human approval.
- Agents should handle research, idea generation, and structured decision support.
- Agents should never send paid ads, outreach emails, or budget changes on their own.
- Each agent should reference documented SOPs and platform policy constraints.
