## Goal

Create a simple landing page that centralizes fans, music links, and email capture.

## Why this matters

A landing page turns social and ad traffic into a measurable action point.

## Prerequisites

- Artist profile
- Release assets
- Email signup capability

## Accounts & tools

- Carrd, Linktree, or website builder
- Email provider
- Analytics tracker

## Estimated cost

- FREE with basic tools.
- PAID for premium landing pages or custom domains.

## Time required

- 2–4 hours to create the page.

## Step-by-step

### Step 1 — choose the landing page tool

Pick a simple, fast builder.

### Step 2 — design the page

Include:
- Artist name and short story
- Release highlight or featured song
- Spotify and streaming links
- Social links
- Email signup form
- Optional exclusive offer

### Step 3 — add tracking

- UTM parameters for campaign links
- Google Analytics or page analytics
- Meta Pixel if using Meta ads

### Step 4 — publish and test

- Check the page on mobile and desktop.
- Test the email signup.
- Verify that links work.

## What you should see

- A live landing page.
- Working links.
- Email capture working.

## What to record

- Page URL.
- Link sources.
- UTM system.

## Metrics

- Page views
- Link clicks
- Email signups
- Conversion rate

## Common errors

- Too much content.
- Broken links.
- No clear CTA.

## Troubleshooting

- If signups don’t work, verify the email form.
- If clicks are low, simplify the page.
- If the page is slow, remove heavy elements.

## Notes

- Keep the landing page focused on one main action.
- Use it as your central campaign destination.
