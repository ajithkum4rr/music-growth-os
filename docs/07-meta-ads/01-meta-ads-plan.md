# Phase 7 — Meta Ads Plan

## Goal

Build a small first Meta ad test plan that supports your release objectives.

## Why this matters

A structured ad plan helps you learn the platform quickly and avoid wasted spend.

## Step-by-step

### Step 1 — choose an objective

Pick one goal for the first test:
- traffic to landing page
- engagement on a post
- reach for a new release

### Step 2 — define the audiences

Create a simple funnel:
- cold audience: interest-based or lookalike
- warm audience: page / profile engagers
- hot audience: recent website or email visitors

### Step 3 — choose creative

Use one or two ad creatives for the test:
- a short release teaser video
- a visual post with release copy
- a link to a landing page with email signup

### Step 4 — set budget and duration

Start small and learn fast:
- an initial test budget of 10–20 USD per day
- a 5–7 day test window

### Step 5 — review metrics

Track simple metrics:
- impressions
- CTR
- link clicks
- conversion actions

## What to record

- Campaign objective
- Audience definitions
- Creative notes
- Budget and timeline

## Common mistakes

- Testing too many audiences at once.
- Using too many creative variations.
- Skipping a clear success metric.

## Notes

- Keep the first test lean and human-reviewed.
- Use the results to refine the next round.
