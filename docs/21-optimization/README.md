## Goal

Use performance data to improve campaigns, creative, and funnels.

## Why this matters

Optimization reduces waste and amplifies what works.

## Prerequisites

- Campaign performance data
- Tracking in place
- Clear goals

## Accounts & tools

- Ads Manager
- Analytics dashboards
- Experiment tracker

## Estimated cost

- FREE if you use existing data.
- PAID only if you invest in more testing budget.

## Time required

- 3–6 hours per optimization cycle.

## Step-by-step

### Step 1 — identify weak points

Review:
- low CTR
- low landing page conversion
- high ad cost
- weak Spotify engagement

### Step 2 — define the hypothesis

Example:
- IF CTR is low, THEN the creative or hook is weak.

### Step 3 — design one experiment

- control: current creative or audience
- test: new creative or targeting
- budget and duration
- success and failure criteria

### Step 4 — run the experiment

- keep one variable changed at a time
- monitor results
- avoid premature decisions

### Step 5 — decide and update

- keep the winner
- pause the loser
- document the decision

## What you should see

- An optimization plan.
- A defined experiment.
- Clear learnings.

## What to record

- Hypothesis.
- Test details.
- Results.
- Decision.

## Metrics

- CTR
- conversion rate
- cost per result
- improvement percentage

## Common errors

- Changing multiple variables at once.
- Stopping tests too early.
- Ignoring data quality.

## Troubleshooting

- If an experiment is inconclusive, extend it.
- If the results are noisy, increase sample size.
- If the winner is unclear, rerun the test.

## Notes

- Optimization is an ongoing process.
- Treat every change as an experiment.
