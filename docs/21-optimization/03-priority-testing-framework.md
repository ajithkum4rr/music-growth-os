# Phase 21 — Optimization Priority Testing Framework

## Goal

Focus optimization efforts on the highest-impact tests first.

## Why this matters

Optimization resources are limited. Prioritizing the right experiments helps you move faster and learn more.

## Priority framework

### 1. choose the biggest opportunity

Start with tests that could improve the metrics that matter most:
- conversion rate
- average listen duration
- email signup rate
- ad ROI

### 2. estimate impact vs effort

Rank experiments by:
- expected benefit
- required work
- risk of disruption

### 3. run one clear test at a time

Avoid testing too many variables simultaneously.
Focus on one hypothesis and one change.

### 4. validate with data

Use metrics that directly reflect the goal of the test.
Stop the test when the result is clear.

### 5. codify the learning

Document what worked and why so the next release can benefit.

## Example priorities

- improve landing page headline copy
- reduce email CTA friction
- test a higher-performing ad creative
- refine playlist outreach subject lines
- simplify signup form fields

## Checklist

- [ ] optimization opportunities listed
- [ ] impact and effort estimated
- [ ] tests scoped clearly
- [ ] data measures defined
- [ ] learning documented

## Notes

- Prioritize tests that support release goals, not vanity metrics.
- Keep the framework simple enough to use consistently.
