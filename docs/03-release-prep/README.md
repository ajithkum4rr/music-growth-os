## Goal

Prepare your music release with a realistic plan and all required assets.

## Why this matters

A great release needs more than a song. It needs delivery readiness, metadata accuracy, visuals, and a promotion roadmap.

## Prerequisites

- Finished or near-finished music
- Basic artist positioning
- A release target window

## Accounts & tools

- Distributor dashboard
- Spotify for Artists
- Asset storage (Google Drive, Dropbox)
- Metadata spreadsheet

## Estimated cost

- FREE for planning.
- PAID only if you use paid mastering, artwork, or distribution upgrades.

## Time required

- 4–10 hours to capture assets and define the plan.

## Step-by-step

### Step 1 — confirm release details

- Track title(s)
- Release type (single, EP, album)
- Release date window
- Distribution provider and delivery deadline

### Step 2 — collect and review assets

- Final audio files
- Cover artwork
- Credits and metadata
- Short track descriptions
- Promotional images and videos

### Step 3 — build the release timeline

Define a timeline from T-8 weeks to T+4 weeks:
- Pre-release research and planning
- Content and landing page prep
- Release announcement
- Post-release review

### Step 4 — document distribution needs

- Distributor requirements
- Release metadata
- ISRC, UPC, and credits
- Release notes for Spotify pitch

### Step 5 — track readiness

- Mark each asset: ready, in progress, or missing.
- Note any dependencies or approvals needed.

## What you should see

- A release plan document.
- A timeline with concrete milestones.
- An asset readiness list.
- A metadata and distribution tracker.

## What to record

- Track details and metadata.
- Release delivery dates.
- Asset status.
- Distributor notes.

## Metrics

- Asset completion rate
- Timeline milestones met
- Release window certainty

## Common errors

- Waiting until the last minute to upload assets.
- Missing metadata or incorrect artist names.
- Assuming a release date is confirmed before distribution approval.

## Troubleshooting

- If your distributor needs more time, move the date back.
- If artwork is not final, use a simple fallback design for planning.
- If you need a release note, write the honest story of the song.

## Notes

- This phase is the bridge from music creation to marketing execution.
- Keep communications with any collaborators clear and documented.
