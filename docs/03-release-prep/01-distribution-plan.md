# Phase 3 — Distribution Plan

## Goal

Document how your release will be delivered to stores, playlists, and artist platforms.

## Why this matters

A clear distribution plan prevents delays, metadata mistakes, and release date problems.

## Step-by-step

### Step 1 — identify your distributor

Note the service you will use and its delivery requirements.
- Distributor name
- Latest upload deadline
- Metadata format
- Artwork specifications

### Step 2 — gather release metadata

Collect:
- Track titles and versions
- Artist and label names
- Genre and mood tags
- Composer and producer credits
- Explicit/clean status

### Step 3 — confirm release assets

Verify:
- Final audio files
- Cover artwork
- Release copy and descriptions
- Credits and credits order

### Step 4 — schedule the release

Set a target release date and delivery checkpoints:
- Distribution upload date
- Spotify pitch due date
- Landing page live date
- Email announcement date

### Step 5 — note open items

Track what is still pending:
- Audio revision
- Artwork delivery
- License or sample clearance
- Distributor approval

## What to record

- Distributor and deadline details
- Metadata checklist
- Asset readiness notes
- Release schedule milestones

## Common mistakes

- Uploading with incorrect metadata.
- Missing the distributor’s deadline.
- Using wrong artwork dimensions.

## Notes

- Keep this plan updated as assets change.
- Share it with collaborators if you’re working with a team.
