# Phase 3 — Release Distribution Checklist

## Goal

Verify that the release is ready for distribution and configured correctly with your distributor.

## Why this matters

Distribution errors can delay your release and impact playlist pitching, press outreach, and analytics.

## Checklist

- [ ] distributor account is active
- [ ] release date is confirmed
- [ ] audio files are final and formatted correctly
- [ ] cover artwork meets distributor specs
- [ ] metadata is complete and accurate
- [ ] artist credits and contributors are listed correctly
- [ ] pre-save / pre-add links are set up if needed
- [ ] publishing territories are correct
- [ ] release notes are provided for Spotify pitch
- [ ] release confirmation is received

## Notes

- Double-check spelling of artist and track names.
- Keep a backup of all final assets and metadata.
