# Phase 25 — POST-CAMPAIGN ANALYSIS

## Folder contents

- 01-post-campaign-review.md
- 02-post-campaign-summary-template.md
- 03-post-campaign-action-plan-template.md


## Goal

Review the release campaign and capture the lessons for the next cycle.

## Why this matters

Analysis turns one campaign into repeatable improvement.

## Prerequisites

- completed release campaign
- recorded performance data

## Accounts & tools

- analytics dashboard
- campaign tracker
- notes or post-mortem template

## Estimated cost

- FREE.

## Time required

- 3–5 hours for a thorough review.

## Step-by-step

### Step 1 — collect results

Gather:
- stream numbers
- social performance
- landing page conversions
- email results
- ad spend and returns

### Step 2 — compare against goals

- what was expected?
- what delivered?
- what missed?

### Step 3 — identify wins and losses

- what worked well?
- what underperformed?
- what surprised you?

### Step 4 — write the post-mortem

Include:
- outcome summary
- key learnings
- next action items

### Step 5 — update your process

- adjust the roadmap
- revise the release playbook
- note experiments for next time

## What you should see

- A post-campaign report.
- documented learnings.
- updated next-step plan.

## What to record

- final metrics.
- outcomes.
- decisions.

## Metrics

- performance vs goals
- learnings captured
- next actions created

## Common errors

- Focusing only on positives.
- Not recording failures.
- Skipping the follow-up process.

## Troubleshooting

- If data is incomplete, note missing pieces.
- If you are unsure of the cause, identify hypotheses.
- If the review feels shallow, revisit the metrics.

## Notes

- The goal is learning, not assigning blame.
- Use this analysis to improve the next release.
