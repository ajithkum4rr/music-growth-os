## Goal

Build a repeatable content engine that supports the release and grows your profile.

## Why this matters

Content is the fuel for discovery, engagement, and the funnel that leads people to your music.

## Prerequisites

- Artist positioning
- Release concept
- Audience archetypes

## Accounts & tools

- Social platform accounts
- Content calendar or simple planner
- Video and image creation tools

## Estimated cost

- FREE to start.
- PAID only if you use production tools or editing services.

## Time required

- 4–8 hours to create the first content matrix.

## Step-by-step

### Step 1 — define content categories

Use categories such as:
- Story
- Production
- Behind-the-scenes
- Performance
- Lyrics
- Visualizer
- Teaser
- Release announcement
- Post-release update

### Step 2 — build a content matrix

For each category, define:
- Hook
- Body
- CTA
- Format
- Platform
- Audience stage
- Purpose

### Step 3 — choose formats per platform

Match content to the platform:
- TikTok: short, native, trend-aware clips
- Instagram: Reels, Stories, carousels
- YouTube: videos, shorts, premieres
- Spotify: Canvas, artist post, playlist clips

### Step 4 — plan multiple creatives

From one song, create:
- A teaser clip
- A story video
- A behind-the-scenes moment
- A lyric or mood visual
- A follow-up post with a CTA

### Step 5 — document production workflow

Write the steps for:
- Idea capture
- Filming / creation
- Editing
- Posting and scheduling
- Performance review

## What you should see

- A content matrix.
- A production plan.
- A content calendar.
- A set of 3–5 ready content ideas.

## What to record

- Content themes.
- Platform formats.
- Creative notes.
- Publishing schedule.

## Metrics

- Content volume
- Engagement by format
- Reach and impressions
- Conversion actions

## Common errors

- Creating content without a clear CTA.
- Using the same format on all platforms.
- Posting without a plan or follow-up.

## Troubleshooting

- If content feels weak, return to your brand story.
- If a format doesn’t fit the platform, shift to a more native version.
- If you can’t produce everything, prioritize the highest-value pieces.

## Notes

- The content system is iterative. Start with simple ideas and improve.
- Focus on consistency over perfection.
