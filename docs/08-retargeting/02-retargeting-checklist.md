# Phase 8 — Retargeting Checklist

## Goal

Track your retargeting setup and make sure audiences are ready for follow-up campaigns.

## Checklist

- [ ] Define cold, warm, and hot audience segments
- [ ] Set audience membership windows
- [ ] List retargeting exclusions
- [ ] Assign creative themes for each audience
- [ ] Confirm tracking pixels or events are firing
- [ ] Map the retargeting schedule
- [ ] Plan the follow-up offer or CTA
- [ ] Review audience overlap and exclusions
