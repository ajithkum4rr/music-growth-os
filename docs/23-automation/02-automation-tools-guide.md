# Phase 23 — Automation Tools Guide

## Goal

Choose the right tools for safe automation in your music marketing workflow.

## Why this matters

The right tools help you automate repetitive tasks without losing control of creative decisions.

## Step-by-step

### Step 1 — list repeatable tasks

Identify tasks that can be automated safely:
- reporting exports
- reminders and due-date alerts
- scheduled social posts
- analytics summaries

### Step 2 — choose tools by use case

Examples:
- Zapier or Make for workflow automation
- Notion or Airtable for task reminders
- email provider automations for follow-ups
- scheduling tools for social posts

### Step 3 — define manual checkpoints

For each automation, decide what must stay manual:
- campaign launch approvals
- ad budget changes
- creative finalization

### Step 4 — document tool setup

Record:
- tool name
- purpose
- trigger
- action
- human review step

## What to record

- automation candidates
- tool selection notes
- approval workflow

## Common mistakes

- automating strategic decisions.
- relying on automation for urgent or creative work.
- neglecting review steps.

## Notes

- Start with one tool and one workflow.
- Keep automation simple and transparent.
