## Goal

Identify safe automation opportunities for recurring tasks.

## Why this matters

Automation frees time and ensures consistency when done responsibly.

## Prerequisites

- documented workflows
- simple repeatable tasks
- platform stability

## Accounts & tools

- scripting environment or automation tool
- spreadsheet or tracker
- secure credentials storage

## Estimated cost

- FREE with basic scripts.
- PAID for automation platforms.

## Time required

- 3–5 hours to define and prototype the first automation.

## Step-by-step

### Step 1 — list repeatable tasks

- weekly reporting
- UTM generation
- outreach reminders
- content calendar creation

### Step 2 — classify automation candidates

- fully automatable
- human-in-the-loop
- manual only

### Step 3 — build the first automation

- choose a safe task
- write the script or use a template
- keep human approval in the loop

### Step 4 — document the process

- what triggers the automation
- what data it uses
- when a human reviews it

### Step 5 — test carefully

- verify results
- do not automate external actions without approval
- keep a rollback plan

## What you should see

- A first automation candidate.
- A documented workflow.
- A test result.

## What to record

- Task definition.
- Automation design.
- Human review points.

## Metrics

- time saved
- error reduction
- task completion consistency

## Common errors

- Automating decisions too early.
- Skipping human review.
- Using real credentials in scripts.

## Troubleshooting

- If automation is buggy, simplify it.
- If it affects accounts, stop and review.
- If it is too weak, keep it manual.

## Notes

- Automation is a support layer, not the strategy.
- Keep it safe and minimal at first.
