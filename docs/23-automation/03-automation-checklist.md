# Phase 23 — Automation Checklist

## Goal

Ensure automation is used safely and effectively in your marketing workflow.

## Checklist

- [ ] Identify repeatable tasks suitable for automation
- [ ] Choose tools that support your workflow
- [ ] Define clear triggers and actions
- [ ] Keep a manual approval point for strategic decisions
- [ ] Document each automation rule
- [ ] Monitor automated workflows regularly
- [ ] Update automations after each campaign cycle

## Notes

- Avoid automating creative or budget decisions.
- Use automation to reduce busywork, not to replace judgment.
