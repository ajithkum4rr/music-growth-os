# Phase 23 — Automation Prioritization Guide

## Goal

Choose the highest-impact automation tasks to build first.

## Why this matters

Automation should save time, not create extra complexity.

## Prioritization rules

### 1. automate repeatable tasks

Start with tasks you do every week:
- email follow-ups
- social post publishing
- reporting exports

### 2. require minimal maintenance

Prefer automations that don’t need daily tuning.

### 3. support a clear business outcome

Automate tasks that directly improve efficiency or fan growth.

### 4. avoid over-automation

If a task needs judgment or creativity, keep it manual.

## Example priorities

- email campaign scheduling
- social media publishing workflow
- ad performance reporting
- playlist outreach reminders
- analytics dashboard refresh

## Checklist

- [ ] candidate tasks listed
- [ ] impact estimated
- [ ] maintenance needs assessed
- [ ] automation plan created
- [ ] pilot automation launched

## Notes

- Review automations monthly to confirm they still help.
- Document each automation outcome clearly.
