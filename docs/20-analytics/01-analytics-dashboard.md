# Phase 20 — Analytics Dashboard

## Goal

Create a simple analytics dashboard that tracks the core funnel metrics for your campaign.

## Why this matters

Analytics helps you see what is working, where fans are coming from, and which channel deserves more focus.

## Step-by-step

### Step 1 — choose your core metrics

Pick 4–6 metrics such as:
- website / landing page visits
- email signups
- Spotify streams
- social engagement
- ad click-through rate
- conversion rate

### Step 2 — define data sources

List where each metric comes from:
- Google Analytics / GA4
- email provider reports
- Spotify for Artists
- Ads Manager
- social platform analytics

### Step 3 — build the dashboard

Use a spreadsheet, doc, or simple dashboard tool.
Track:
- metric
- target
- actual
- trend notes

### Step 4 — review weekly

Set a regular review time:
- what improved?
- what stalled?
- what is the next test?

## What to record

- Metric definitions
- Data sources
- Weekly results
- Insight notes

## Common mistakes

- Tracking too many metrics.
- Using metrics without a clear goal.
- Reviewing data only after the campaign ends.

## Notes

- Keep the first dashboard lean.
- Focus on what moves listener growth and engagement.
