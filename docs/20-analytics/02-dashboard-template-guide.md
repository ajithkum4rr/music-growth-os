# Phase 20 — Analytics Dashboard Template Guide

## Goal

Provide a simple template for building a campaign analytics dashboard.

## Why this matters

A dashboard template makes metrics easy to track and improves clarity across reviews.

## Step-by-step

### Step 1 — choose your core metrics

Include only the most important numbers, such as:
- landing page visits
- email signups
- stream counts
- ad clicks
- conversion rates

### Step 2 — define the source for each metric

List where the data comes from:
- Google Analytics / GA4
- email provider
- Spotify for Artists
- Ads Manager

### Step 3 — create a clean layout

Use a simple table with columns:
- metric
- target
- actual
- change
- notes

### Step 4 — add insights section

Include a short summary:
- what is working
- what needs attention
- next actions

## What to record

- dashboard structure
- metric sources
- review cadence
- insight summary

## Common mistakes

- tracking too many metrics.
- mixing raw counts with rate-based metrics without context.
- skipping the insight summary.

## Notes

- Keep the dashboard easy to update.
- Use it weekly during launch and optimization.
