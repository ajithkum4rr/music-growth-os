## Goal

Measure performance across the funnel and understand what is actually working.

## Why this matters

Analytics turn activity into decisions. Without them, you cannot optimize reliably.

## Prerequisites

- Tracking systems in place
- Campaign activity under way
- Data capture plan

## Accounts & tools

- Platform analytics dashboards
- Google Analytics / GA4
- Spreadsheet or reporting tool

## Estimated cost

- FREE.

## Time required

- 4–6 hours to build the first dashboard.

## Step-by-step

### Step 1 — define useful metrics

Track:
- impressions
- clicks
- streamers
- follows
- landing page conversions
- email signups
- cost metrics

### Step 2 — classify metrics

- Vanity: reach, impressions
- Business: clicks, conversions, streams, email signups
- Quality: saves, follows, repeat listens

### Step 3 — build attribution categories

- Directly measurable: ad and web sources
- Inferred: playlist discovery, organic social influence
- Unknown: offline or untacked word-of-mouth

### Step 4 — create your dashboard

Include:
- source performance
- funnel conversion rates
- cost per result
- audience segment comparison

### Step 5 — review regularly

Schedule review:
- weekly for campaigns
- daily during launch spikes

## What you should see

- A simple dashboard.
- Attribution notes.
- Weekly review cadence.

## What to record

- Data sources.
- Metric definitions.
- A summary of key findings.

## Metrics

- Conversion rates
- Cost per listener
- Cost per email signup
- Repeat listener rate

## Common errors

- Counting every metric as equally important.
- Ignoring attribution limitations.
- Comparing metrics across incompatible channels.

## Troubleshooting

- If data is inconsistent, verify tracking IDs.
- If attribution is unclear, label the uncertainty.
- If a metric is stale, refresh the dashboard approach.

## Notes

- Analytics are only useful if they guide action.
- Never let a metric stand alone without context.
