# Phase 0 — Release Inventory

## Goal

Capture the assets, dates, and launch details for your first release.

## Why this matters

A clear release inventory prevents last-minute missing assets and keeps the launch manageable.

## What this includes

- Song list and versions
- Artwork and visuals
- Metadata and credits
- Release timeline
- First metrics to track

## Step-by-step

### Step 1 — list your songs

For each track, record:
- Title
- Version (single, radio edit, instrumental)
- Status: final / mastering / needs revision
- BPM / key (optional)

### Step 2 — record your artwork and visuals

List all visual assets:
- Cover art
- Promotional images
- Video concepts
- Social format previews

### Step 3 — compile metadata

Gather the metadata you need for distribution:
- Artist name
- Release title
- Genre
- Record label (if any)
- Composer and producer credits
- Release date window

### Step 4 — define your timeline

Create a simple release timeline with these milestones:
- T-8 weeks: release planning starts
- T-6 weeks: first content and audience research
- T-4 weeks: landing page + email capture ready
- T-2 weeks: organic and paid promotion begins
- Release day: track goes live
- T+1 week: early review and optimization
- T+4 weeks: post-campaign analysis

### Step 5 — choose your first metrics

Select 3–5 core metrics for this release:
- Spotify streams
- Spotify saves and follows
- Landing page clicks
- Email signups
- Social engagement

## What to record

- Release plan document
- Asset readiness status
- Timeline dates
- Metric tracking plan

## Common mistakes

- Leaving metadata until the last minute.
- Releasing without a landing page or email capture.
- Not defining a clear release window.
- Tracking too many metrics too early.

## Troubleshooting

- If you don’t know the exact release date, use a tentative date and update it.
- If artwork is incomplete, identify the minimum required asset to move forward.
- If email capture is not ready, use a basic landing page with a signup form.

## Notes

- This inventory is a planning tool, not a final delivery checklist.
- Keep the release plan simple and actionable.

## Advanced notes

- Later, this inventory becomes the basis for campaign and ad planning.
- You can add distribution notes when you submit to a distributor.
