# Phase 9 — Spotify Metrics Guide

## Goal

Track the key Spotify metrics that matter for your release performance.

## Why this matters

The right metrics help you understand how listeners discover your music and whether your release is gaining traction.

## Core metrics

- Streams: total plays for the release period.
- Saves: listeners saving the track to playlists.
- Follows: new artist followers from the release.
- Listeners: unique listener count.
- Playlist sources: which playlists drove streams.
- Release radar and algorithmic sources.

## How to use them

### Baseline

Capture the current numbers before launch. This helps you compare post-launch performance.

### Weekly review

Compare week-over-week changes and note the direction of the trends.

### Action triggers

- Low saves: improve the release CTA and follow-up messages.
- Low playlist referrals: revisit your playlist targeting.
- Strong follower growth: amplify social and email promotion.

## What to record

- baseline metrics
- weekly metric changes
- source breakdowns
- insights and actions

## Common mistakes

- focusing only on stream totals.
- ignoring saves and followers.
- not comparing to a baseline.

## Notes

- Use Spotify metrics with other campaign data, not in isolation.
- Track the metrics consistently each week.
