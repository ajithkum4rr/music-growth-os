## Goal

Set up the accounts, tools, and tracking required for performance.

## Why this matters

Infrastructure is the backbone for organic growth, paid campaigns, and analytics.
Without it, you can’t measure or scale reliably.

## Prerequisites

- Basic artist profile
- Release projection or plan
- Initial platform accounts

## Accounts & tools

- Meta Business Manager
- Spotify for Artists
- Email service
- Landing page tool
- Analytics tracker
- File storage system

## Estimated cost

- FREE to low cost.
- PAID for premium email plans, landing pages, or analytics integrations.

## Time required

- 4–6 hours for setup and verification.

## Step-by-step

### Step 1 — confirm accounts

Make sure you have:
- Meta accounts connected
- Spotify for Artists access
- Email provider ready
- Landing page created
- Analytics tracking available

### Step 2 — secure the environment

- Enable 2FA on all platforms.
- Use a password manager.
- Keep account ownership under your name.

### Step 3 — set up tracking

If you have a landing page or website, add:
- Google Analytics / GA4
- UTM naming convention
- Meta Pixel if you plan to use Meta ads later

### Step 4 — centralize assets

Create a shared folder for:
- Audio files
- Artwork
- Video drafts
- Copy and captions
- Documents and timelines

## What you should see

- Connected accounts.
- A working landing page.
- Basic analytics tracking.
- A secured account setup.

## What to record

- Account URLs.
- Tool purpose and login notes.
- Tracking IDs.
- Asset folders.

## Metrics

- Accounts connected
- Tracking implemented
- Asset storage readiness

## Common errors

- Forgetting to enable 2FA.
- Using inconsistent login emails.
- Not verifying analytics setup.

## Troubleshooting

- If analytics data is missing, verify the tracking ID.
- If account access is blocked, check platform verification.
- If the landing page isn’t working, simplify it to a single link page.

## Notes

- Infrastructure is more than accounts; it is the measurement plan.
- Keep the setup simple and consistent.
