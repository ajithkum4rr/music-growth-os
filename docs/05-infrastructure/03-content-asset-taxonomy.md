# Phase 5 — Content Asset Taxonomy

## Goal

Organize your release assets so they are easy to find and reuse.

## Why this matters

A clean asset taxonomy saves time and prevents duplicate work during launch.

## Asset categories

### Release assets
- audio masters
- artwork files
- metadata docs

### Content assets
- social images
- video reels
- quote graphics
- short-form clips

### Promotion assets
- ad creative
- landing page assets
- email banners
- press kit files

### Reference assets
- brand guidelines
- audience research notes
- campaign briefs

## Naming conventions

Use consistent names:
- `2026-09-release-artwork-v1.jpg`
- `release-email-copy-01.md`
- `insta-reel-behind-the-song.mp4`

## Folder structure example

- `assets/release/`
- `assets/content/`
- `assets/ads/`
- `assets/docs/`

## Notes

- Store final versions separately from drafts.
- Add tags or a simple index if your storage supports it.
