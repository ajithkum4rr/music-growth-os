# Phase 5 — Asset Organization Guide

## Goal

Create a simple asset organization system for release files and marketing materials.

## Why this matters

Organized assets save time and reduce errors during launch execution.

## Step-by-step

### Step 1 — create main folders

Suggested structure:
- Audio
- Artwork
- Video
- Social assets
- Copy / messaging
- Press / outreach
- Analytics / tracking

### Step 2 — name files consistently

Use clear, consistent file names:
- 01_Single_Title_Master.mp3
- 02_Release_Cover_1080x1080.png
- 03_TikTok_Hook_1.mov

### Step 3 — track versions

Keep version notes for files under revision:
- _v1
- _v2
- _final

### Step 4 — keep notes with assets

Record the asset purpose and status:
- ready
- needs revision
- approved

## What to record

- folder structure
- naming rules
- versioning notes
- status labels

## Common mistakes

- storing files across too many locations.
- using vague file names.
- losing track of the latest version.

## Notes

- Use this guide for all release-related files.
- Keep the system simple and easy to maintain.
