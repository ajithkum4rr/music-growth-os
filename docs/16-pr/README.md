## Goal

Build a practical PR outreach process for blogs, podcasts, and media.

## Why this matters

PR can earn credibility and reach audiences beyond your immediate network.

## Prerequisites

- Release ready or imminent
- Artist story and pitch angle
- Media target list

## Accounts & tools

- Spreadsheet or CRM
- Email or outreach tool
- Pitch templates

## Estimated cost

- FREE to start.
- PAID only if you use premium PR services.

## Time required

- 5–8 hours to research and start outreach.

## Step-by-step

### Step 1 — understand PR

PR includes:
- blogs and magazines
- podcasts
- radio and playlists
- interviews and premieres
- reviews and features

### Step 2 — build a media list

Collect:
- publication name
- contact person
- email or submission form
- editorial focus
- deadlines or windows

### Step 3 — craft a pitch

Include:
- a compelling hook
- artist story
- release details
- why it fits their audience

### Step 4 — personalize outreach

Use each contact’s name and reference recent coverage where possible.

### Step 5 — track follow-up

- initial email sent
- follow-up date
- response status
- outcome

## What you should see

- A PR target list.
- A pitch template.
- Outreach tracking.

## What to record

- Contact details.
- Message copy.
- Responses.
- Coverage obtained.

## Metrics

- Outreach sent
- Responses
- Placements or features

## Common errors

- Sending generic pitches.
- Targeting irrelevant media.
- Not tracking outreach.

## Troubleshooting

- If no responses, improve personalization.
- If coverage is weak, refine the angle.
- If deadlines are missed, update the tracker.

## Notes

- PR is about relationships and relevance.
- Avoid spammy mass emailing.
