# Phase 16 — PR Measurement Guide

## Goal

Measure PR activity to understand what coverage moves the needle.

## Why this matters

PR should be judged by reach, relevance, and how it contributes to fan growth.

## Core PR metrics

- placements secured
- domain authority or audience size
- referral traffic to landing page
- social shares and mentions
- email and streaming uplifts

## How to measure

### 1. track placements

Capture each placement with:
- outlet name
- publish date
- story angle
- link or mention type

### 2. set up referral tracking

Use UTM links for PR-related traffic to your landing page or music pages.

### 3. assess quality

Look beyond raw impressions:
- did the audience match your ideal fans?
- was the coverage well-aligned with your release?

### 4. compare outcomes

Match PR activity against other channels for the same period.

## Checklist

- [ ] placements logged
- [ ] referral links tracked
- [ ] coverage quality assessed
- [ ] campaign impact compared to other channels
- [ ] learnings recorded

## Notes

- Value PR for its awareness and credibility, not only direct conversions.
- Use measurement to improve future outreach and story angles.
