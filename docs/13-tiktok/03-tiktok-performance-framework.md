# Phase 13 — TikTok Performance Framework

## Goal

Track and optimize TikTok content using a simple performance framework.

## Why this matters

TikTok rewards consistent creative patterns and quick learning from what performs.

## Framework

### 1. define the signal

Choose one performance signal to monitor:
- views
- watch time
- likes
- shares
- comments

### 2. compare creative variants

Test small changes across videos:
- hook wording
- visual opener
- CTA format
- trending sound vs original audio

### 3. capture context

Record what changed:
- publish time
- caption copy
- hashtag set
- audience response

### 4. decide next step

If a video performs well, do one of these:
- double down on the same style
- replicate the hook in a new variation
- promote it with other channels

If it underperforms:
- pause similar creative
- revise the concept
- test a new idea

## Checklist

- [ ] performance signal selected
- [ ] creative variants defined
- [ ] publish details logged
- [ ] results recorded
- [ ] next action documented

## Notes

- Small, fast tests are more valuable than guessing.
- Keep the framework simple enough to use every week.
