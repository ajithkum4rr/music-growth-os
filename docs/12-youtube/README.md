## Goal

Create a YouTube strategy that supports music discovery and artist storytelling.

## Why this matters

YouTube is a search and discovery platform with strong potential for music exposure.

## Prerequisites

- YouTube channel
- Visual assets or video ideas
- Release content plan

## Accounts & tools

- YouTube channel
- Video editing tools
- Thumbnail creator

## Estimated cost

- FREE to start.
- PAID if you use editing software or production help.

## Time required

- 4–8 hours to define strategy and create the first assets.

## Step-by-step

### Step 1 — optimize the channel

- Channel name and description.
- Banner and profile image.
- About section with links.

### Step 2 — choose video types

- Single audio visualizer or lyric video
- Shorts with hooks or behind-the-scenes
- Performance or studio snippets
- Release announcement video

### Step 3 — set posting cadence

- Release one main video or short weekly.
- Use Shorts for frequent visibility.

### Step 4 — optimize metadata

- Use descriptive titles.
- Add keyword-rich descriptions.
- Include links to your landing page.
- Use tags and playlists.

### Step 5 — monitor watch metrics

Track:
- Views
- Watch time
- Subscribers
- Traffic sources

## What you should see

- A clear channel plan.
- Optimized metadata.
- At least one YouTube asset ready.

## What to record

- Video ideas.
- Publishing schedule.
- Performance notes.

## Metrics

- Views
- Watch time
- Subscribers
- Engagement

## Common errors

- Using poor titles or descriptions.
- Uploading without a plan.
- Ignoring YouTube search optimization.

## Troubleshooting

- If views are low, improve thumbnails and titles.
- If watch time is low, simplify the format.
- If uploads are inconsistent, reduce the cadence.

## Notes

- YouTube success often requires persistence.
- Use Shorts to test ideas quickly.
