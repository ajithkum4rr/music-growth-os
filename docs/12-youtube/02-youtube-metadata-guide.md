# Phase 12 — YouTube Metadata Guide

## Goal

Optimize your YouTube titles, descriptions, and tags for music discovery.

## Why this matters

Good metadata helps your videos show up in search and recommendations.

## Step-by-step

### Step 1 — craft a strong title

Include:
- artist name
- track name
- release format or theme
Example: `ajkay — [Track Title] | New Single`

### Step 2 — write a useful description

Include:
- short release summary
- streaming and landing page links
- social links
- credits or collaborators

### Step 3 — choose tags and categories

Use tags that reflect:
- genre
- mood
- release type
- related artist references

### Step 4 — add a clear CTA

Ask viewers to:
- listen on Spotify
- subscribe
- follow on social

## What to record

- title format
- description template
- tags list

## Common mistakes

- missing links in the description.
- using vague or generic titles.
- ignoring the video category.

## Notes

- You can update metadata after publishing.
- Keep the first line of the description the most important.
