## Goal

Plan an AI-assisted system that helps with research, analytics, and recommendations.

## Why this matters

AI can speed analysis and insight generation, but only after the process is documented.

## Prerequisites

- documented SOPs
- structured data
- clear agent roles

## Accounts & tools

- knowledge source repository
- retrieval tool or system
- agent definition files

## Estimated cost

- FREE for planning.
- PAID if using paid AI tools or RAG services.

## Time required

- 4–6 hours to draft the first system.

## Step-by-step

### Step 1 — define RAG source tiers

- Tier 1: official documentation
- Tier 2: official creator/business docs
- Tier 3: reliable industry research
- Tier 4: community and anecdotal sources

### Step 2 — choose the first sources

- Spotify docs
- Meta docs
- YouTube creator docs
- Your own campaign data

### Step 3 — define agent roles

- audience research agent
- content strategy agent
- meta ads agent
- analytics agent
- optimization agent

### Step 4 — write safety rules

- require human approval for external actions
- never spend budget autonomously
- never send outreach without review

### Step 5 — document the system

- agent responsibilities
- inputs and outputs
- decision rules
- RAG sources

## What you should see

- A RAG source hierarchy.
- Agent role definitions.
- Safety and approval rules.

## What to record

- Source list.
- Agent design notes.
- Use case examples.

## Metrics

- source coverage
- agent task readiness
- human review checkpoints

## Common errors

- Treating AI as fully autonomous.
- Using weak or unverified sources.
- Not documenting policy constraints.

## Troubleshooting

- If a source is questionable, label it anecdotal.
- If agents overlap, clarify roles.
- If approval rules are missing, add them.

## Notes

- This phase is planning for future capability.
- Keep human control central.
