# Phase 24 — AI / RAG Agent Guide

## Goal

Document how to use AI and Retrieval-Augmented Generation (RAG) safely within your music marketing system.

## Why this matters

AI can accelerate research and synthesis, but it must be guided by clear rules and reliable sources.

## Step-by-step

### Step 1 — define your RAG sources

List the content sources AI can query:
- phase docs
- SOPs
- campaign notes
- analytics summaries
- approved research files

### Step 2 — document agent roles

Define the purpose of each agent:
- audience research
- content planning
- ads recommendation
- analytics summary
- release campaign coordination

### Step 3 — set safety rules

For each agent, require:
- human approval for action
- no autonomous spending
- no data privacy violations
- no fake growth recommendations

### Step 4 — define input and output expectations

For each agent, note:
- what it needs from you
- what it returns
- how to verify the output

## What to record

- RAG source list
- agent role descriptions
- safety rules
- approval workflow

## Common mistakes

- letting agents make decisions alone.
- relying on outdated or unverified sources.
- using AI for anything that requires personal consent.

## Notes

- Keep human judgment at the center.
- Use AI to summarize and suggest, not to execute.
