# Phase 24 — RAG Data Quality Checklist

## Goal

Keep the retrieval corpus accurate, current, and organized for RAG workflows.

## Why this matters

RAG answers are only as good as the data that powers them.

## Checklist

- [ ] source documents are current
- [ ] metadata tags are correct
- [ ] duplicate entries removed
- [ ] documents are clearly labeled by topic and date
- [ ] retrieval performance is monitored
- [ ] outdated or irrelevant information is archived
- [ ] new campaign docs are added promptly

## Notes

- Review the corpus after every major campaign.
- Use a consistent format for new inputs to reduce retrieval noise.
