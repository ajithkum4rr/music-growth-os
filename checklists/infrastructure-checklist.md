# Infrastructure Checklist

## Goal

Confirm the core infrastructure for your release is set up and organized.

## Checklist

- [ ] Landing page created and tested
- [ ] Email provider account configured
- [ ] Analytics tracking installed on the landing page
- [ ] Social profiles linked to the campaign
- [ ] Asset folders organized and named consistently
- [ ] UTM naming convention documented
- [ ] Key account URLs recorded securely
- [ ] Password manager and 2FA in place for all accounts
