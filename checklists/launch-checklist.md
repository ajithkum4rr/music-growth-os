# Launch Checklist

Use this checklist to track the launch from preparation through the first review.

## Pre-launch

- [ ] Confirm release date and delivery deadlines
- [ ] Verify all release assets are final
- [ ] Set up Spotify for Artists and claim profile
- [ ] Create landing page with email capture
- [ ] Choose and define target audiences
- [ ] Build the first content calendar
- [ ] Set up Meta ads and retargeting plan
- [ ] Prepare PR and playlist outreach lists
- [ ] Connect analytics tracking and UTM rules

## Launch week

- [ ] Publish the landing page
- [ ] Send the email announcement
- [ ] Post release content on priority platforms
- [ ] Launch the first ad test campaign
- [ ] Monitor early metrics daily
- [ ] Capture feedback and engagement notes

## Post-launch

- [ ] Review first-week performance
- [ ] Document lessons learned
- [ ] Adjust content and ad plans
- [ ] Send follow-up retention content
- [ ] Update the repeatable playbook
