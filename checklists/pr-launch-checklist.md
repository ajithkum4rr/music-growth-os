# PR / Launch Checklist

## PR outreach

- [ ] Build press target list
- [ ] Draft personalized PR email
- [ ] Send initial outreach
- [ ] Follow up after 5–7 business days
- [ ] Record responses and placements

## Launch coordination

- [ ] Confirm release date and delivery
- [ ] Launch landing page with email capture
- [ ] Create launch social content
- [ ] Send email announcement
- [ ] Monitor early launch metrics

## Post-launch

- [ ] Review PR and media coverage
- [ ] Share coverage on socials
- [ ] Add results to the repeatable playbook
- [ ] Document lessons learned
